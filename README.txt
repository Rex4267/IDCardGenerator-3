# Web-Based ID Card Generator

## How to Use
1. Open index.html in any browser.
2. Fill in Name, Emp Code, Blood Group, Emergency No.
3. Upload photo.
4. Click "Preview & Download ZIP" to get both PNGs in one ZIP file.

## How to Host Online
### Option 1: Netlify
- Go to https://www.netlify.com/
- Drag and drop this folder.
- Get your live link instantly.

### Option 2: GitHub Pages
- Create a GitHub repo.
- Upload all files.
- Go to Settings → Pages → Enable GitHub Pages.
- Your site will be live at: https://username.github.io/repo-name
